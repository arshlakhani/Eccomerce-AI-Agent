# Autonomous E-commerce Data Analyst Agent

An AI-powered e-commerce analytics platform that allows users to explore business data through natural-language queries. Built using **LangGraph, LangChain, PostgreSQL, FastAPI, and React**, the system uses an LLM-powered agent to select and execute analytical tools, retrieve insights, and present results through a conversational dashboard.

## Overview

Traditional business analytics often requires users to write SQL queries or navigate multiple dashboards to find insights. This project aims to simplify that process by allowing users to ask questions in natural language.

For example:

- What was the total revenue generated by the business?
- Which products generated the highest revenue?
- How has monthly revenue changed over time?
- Which countries contribute the most to total sales?
- Who are the highest-value customers?
- Identify unusual transactions in the dataset.

The AI agent interprets the question, selects the appropriate analytical tools, executes database queries, and generates a natural-language response.

## Key Features

- **Conversational Analytics:** Ask business questions in natural language instead of writing SQL queries.
- **Autonomous Tool Selection:** Uses LangGraph and LLM-powered tool calling to select and execute relevant analytical functions.
- **Revenue Analysis:** Analyse monthly revenue, month-over-month growth, and business performance.
- **Product Analytics:** Identify top-performing products based on revenue and units sold.
- **Customer Analytics:** Analyse customer spending, purchase history, and repeat-purchase behaviour.
- **Geographical Insights:** Compare sales performance across different countries.
- **Anomaly Detection:** Identify unusually large transactions for further review.
- **Dynamic Dashboard:** Display key business metrics retrieved directly from PostgreSQL.
- **REST API:** Expose analytics and conversational agent functionality through FastAPI.

## Dataset

The project uses the **Online Retail Dataset** from Kaggle.

- Source: [Online Retail Dataset – Kaggle](https://www.kaggle.com/datasets/carrie1/ecommerce-data)
- Records: 530,000+ transactions
- Data period: December 2010 – December 2011
- Database: PostgreSQL
- Table: `online_retail`

The dataset contains transaction-level information, including:

- Invoice number
- Product stock code
- Product description
- Quantity purchased
- Invoice date
- Unit price
- Customer ID
- Country
- Revenue
- Month

## Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/arshlakhani/Eccomerce-AI-Agent.git
cd Eccomerce-AI-Agent
```

### 2. Backend Setup

Navigate to the backend directory:

```bash
cd backend
```

Create and activate a virtual environment:

```bash
python -m venv venv
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

### 3. Configure Environment Variables

Create a `.env` file inside the `backend` directory:

```env
POSTGRES_USER=postgres
POSTGRES_PASSWORD=your_password
POSTGRES_HOST=localhost
POSTGRES_PORT=5432
POSTGRES_DB=ecommerce_analytics

OPENAI_API_KEY=your_openai_api_key
```

**Important:** Never commit your `.env` file or expose your API keys and database credentials.

### 4. Database Setup

1. Install and start PostgreSQL.
2. Create a database named `ecommerce_analytics`.
3. Import the cleaned Online Retail dataset into a table named `online_retail`.
4. Ensure the table columns match the names and data types expected by the backend.

### 5. Start the Backend

From the `backend` directory:

```bash
uvicorn main:app --reload
```

The API will be available at:

```text
http://127.0.0.1:8000
```

Interactive API documentation:

```text
http://127.0.0.1:8000/docs
```

### 6. Frontend Setup

Open a separate terminal and navigate to the frontend directory:

```bash
cd frontend
npm install
npm run dev
```

The React application will be available at:

```text
http://localhost:5173
```
